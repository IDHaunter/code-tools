# code-tools
Code tools for developers

## base64.html
Base64 encoder and decoder

## jsonStr.html
JSON escaper and unescaper

## generate_structure.py
Generates a structure.md file with structure and entries. 
Accepts a list of folders as additional parameters
The generated file can be used as context for an LLM.

```shell
python3 generate_structure.py
python3 generate_structure.py helm app 
```
